# 🛍️ Fashion E-Commerce Website

A responsive fashion e-commerce website built using **HTML, Tailwind CSS, and JavaScript**.
This project demonstrates a modern UI with product browsing, filtering, and user interaction features.

---

## ✨ Features

* 🏠 **Home Page**

  * Attractive landing page
  * Featured collections
  * Modern responsive design

* 👗 **Products Page**

  * Dynamic product listing
  * Search functionality
  * Category filtering
  * Size filtering
  * Color filtering
  * Price range filter
  * Sorting options
  * Product cards with images and prices

* 🔐 **Signup Page**

  * User registration form
  * Input validation
  * Password confirmation
  * Error messages for invalid inputs

* 📩 **Contact Us Page**

  * Contact form for users
  * Clean UI layout
  * Easy communication interface

---

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **Tailwind CSS** – Styling and responsive layout
* **JavaScript (Vanilla JS)** – Dynamic functionality and filtering logic
